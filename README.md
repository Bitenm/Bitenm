## Projetos de Estudo

### [EstoqueApp](https://github.com/Bitenm/EstoqueApp)

Aplicativo Android nativo em Java, criado como projeto de demonstração de arquitetura e boas práticas.

- Autenticação local segura (Room + hash de senha SHA-256 com salt — sem senha em texto puro)
- Consumo de API REST com Retrofit + Gson
- Listagem com busca em tempo real, pull-to-refresh e Material Design
- Arquitetura organizada em camadas (`model`, `network`, `db`, `adapter`)

### [CampoMinado](https://github.com/Bitenm/CampoMinado)

Campo Minado desktop em Java com interface gráfica em Swing, desenvolvido como prática de orientação a objetos, interfaces funcionais, expressões lambda e padrão Observer.

- Abertura em cascata, marcação de possíveis minas e checagem de vitória/derrota
- Interface Swing com grade de campos, botão de reinício, cronômetro e contador de marcações
- Comunicação entre modelo e interface com o padrão Observer
- Uso de `Consumer` e lambdas para registrar e reagir a eventos dos campos e do tabuleiro

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)
![Swing](https://img.shields.io/badge/Java_Swing-ED8B00?style=flat-square&logo=openjdk&logoColor=white)

### [SimpleBattleship](https://github.com/Bitenm/SimpleBattleship)

Exercício final do livro *Head First Java*, jogo de batalha naval em Java no terminal — implementado a partir da estrutura base do livro, com bugs corrigidos e testes escritos por conta própria pra praticar JUnit.

- Posicionamento das embarcações calculado sobre um grid representado como array 1D (linha/coluna via divisão e resto)
- Bugs de lógica da versão original identificados e corrigidos (destruição de embarcação não removia da lista; leitura de input quebrava fora de uso interativo)
- Suíte JUnit 5 cobrindo regras de jogo, caso de borda (grid totalmente ocupado) e I/O via redirecionamento de `System.in`/`System.out`
